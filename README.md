## About

**Ironman Guide** turns a long-form Ironman progression route into an in-game RuneLite guide.

Instead of constantly switching between a browser guide, notes, the OSRS Wiki and RuneLite, the plugin aims to show the next objective directly in the client and automatically track progress where possible.

## Guide source

The route is based primarily on the community guide:

**https://ironman.guide/guide/early-game**

The guide is adapted into RuneLite-friendly steps rather than copied directly. Instructions can be split into smaller steps for inventory preparation, banking, navigation, highlights, exact resource requirements and automatic completion.

## Features

- Continuous step-by-step Ironman progression
- Automatic step completion
- NPC, object, ground-item and location highlighting
- Inventory and bank-aware requirements
- Dynamic exact resource calculations
- Dialogue and Make-X guidance
- Current-step bank filter
- Minimap and world map guidance
- Optional **Shortest Path** routing
- **Quest Helper** integration

## Integrations

**Quest Helper**  
Used for detailed quest execution while Ironman Guide manages the wider account progression route.

https://runelite.net/plugin-hub/show/quest-helper

**Shortest Path**  
Optional pathfinding to the current guide target. Enable it from:

```text
Ironman Guide → Navigation → Use Shortest Path plugin
```

https://runelite.net/plugin-hub/show/shortest-path

**Bank Tags**  
RuneLite's built-in Bank Tags system is used for the current-step bank filter.

## Progress
